Sitemap.xml dinamis

Controller satu file, tanpa library. Cache 60 menit menyimpan array polos — bukan Eloquent Collection (config cache menolak unserialisasi kelas).

GET /sitemap.xml  →  200, Content-Type: application/xml; charset=UTF-8

    hall-of-fame/{nama-penyelenggara urlencoded}
