Cara kerja

  • Input kode berada di blok konfirmasi, di bawah kartu paket terpilih — applyPromo() saat blur/enter, tidak menunggu submit.
  • Valid: chip hijau + rincian harga coret → diskon → total. Sumber angka: SaasPlan::effective_price dikurangi diskonUntuk().
  • Ganti paket setelah kode diterapkan → kode dinilai ulang (voucher bisa dibatasi satu paket).
  • Blok rincian hanya muncul bila ada diskon aktif — event tanpa kode melihat UI persis seperti sekarang.

Aturan pesan

  • Satu sebab = satu pesan spesifik — pendaftar tahu apa yang salah, tidak menebak.
  • Kode gagal tidak pernah memotong harga: blok rincian hilang, QRIS tetap nominal penuh.
  • Pesan di bawah input, pola @error Livewire yang sudah dipakai form ini.

Yang dibekukan

  • QRIS ditagih nominal terpotong — bukan harga efektif paket.
  • Tersimpan di event: registration_voucher_id + voucher_discount (snapshot). Hapus/ubah voucher belakangan tidak memengaruhi transaksi berjalan.
  • Webhook settlement membandingkan paidAmount ≥ effective_price − voucher_discount — regresti mismatch dipesan di test.
  • Kuota baru terhitung setelah registration_paid_at terisi (bayar beneran), bukan sekadar daftar.

Panel admin

  • CRUD: kode (uppercase otomatis, unique), tipe, nilai, cap, kuota, paket target (opsional), periode, aktif.
  • Kolom Terpakai dihitung langsung dari eventner paid — tanpa counter tersendiri.

  • Validasi admin: percent ≤ 90 (tidak pernah gratis penuh — QRIS menolak nominal 0).
