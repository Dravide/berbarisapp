Videotron Display

Layar big-screen di venue yang ditampilkan langsung — bukan overlay OBS yang dikomposit di atas video. Satu URL per event, beberapa mode konten, bisa dikendalikan lewat parameter URL atau diputar otomatis (loop) tanpa operator. Dirancang untuk jarak pandang jauh: tipografi besar, kontras tinggi, satu ide per layar.

URL /event/{slug}/videotron · subdomain /videotron Layar 16:9, fit-to-screen Refresh wire:poll 15–30 dtk Tanpa migrasi DB baru

Panel kendali

  • Kartu baru di /eventner/livestream: daftar URL videotron + tombol salin (pola URL preview yang sudah ada).
  • Mode loop: urutan mode + durasi disimpan di settings (videotron_{slug}), default 30 dtk, welcome→vote→rundown→sponsor.

Rencana implementasi

BagianRencana
Routeweb.php: get('/event/{slug}/videotron', VideotronDisplay::class) → event.videotron; subdomain.php: get('/videotron', ...) → subdomain.videotron.
Layoutlayouts.videotron — turun pola layouts.livestream (1920×1080 + scale fit, font & warna tema event, noindex), tapi tanpa asumsi chroma key: latar gelap/terang penuh.
KomponenApp\Livewire\Public\VideotronDisplay — #[Layout('layouts.videotron')], queryString mode, category, group, championCategory; satu metode refreshData() di-wire:poll.15s (vote) / 30s (lainnya).
Modewelcome, drawing, vote, champion, rundown, sponsor, loop — konstanta allowedModes, fallback welcome.
DataSemua sumber sudah ada: registrations.urutan_tampil, voteTransactions, ChampionCalculator (+cache 300 dtk), eventRundowns, landing_partners + sponsors. Tidak ada migrasi baru.
Loop settingSetting::set('videotron_{eventner_id}', json_encode([urutan mode, durasi])) — diatur dari panel eventner.
PanelKartu "Videotron" di livestream/manage.blade.php: URL per mode + salin, satu form kecil urutan/durasi loop.
Testtests/Feature/VideotronDisplayTest.php: tiap mode render datanya; mode invalid → welcome; champion hanya is_public; route terlarang untuk tamu bila event draft; sponsor kosong → fallback welcome.
Urutan kerja1) Komponen + layout + route, 2) mode welcome/drawing/vote, 3) champion/rundown/sponsor, 4) loop + panel, 5) test + suite penuh.
