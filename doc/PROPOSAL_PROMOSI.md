## ✨ **KENAPA BARIS APP?**

### ✅ 1. ALL-IN-ONE PLATFORM
Tidak perlu 5 aplikasi berbeda. Cukup BARIS APP untuk semuanya:

| Fitur | Manfaat |
|---|---|

### ✅ 2. MUDAH DIGUNAKAN
- **Peserta**: Tidak perlu daftar akun — cukup klik magic link dari email
- **Juri**: Buka link, nilai langsung, simpan
- **Panitia**: Satu dashboard untuk semua kontrol
- **Penonton**: Scan QRIS untuk vote, lihat scoreboard real-time

- Session database — aman dari session hijacking lintas subdomain
